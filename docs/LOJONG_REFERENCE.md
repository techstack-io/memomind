# Lojong Reference — Internal Working Document

**Not for publication.** This is a working checklist for MemoMind's authoring
process, not public-facing content. The traditional numbering and 7-point
grouping below follows Chekawa Yeshe Dorje's 12th-century root text — the
version most commentators (Chödrön, Fischer, Lief, Trungpa) work from, and
the version this project is built against.

The one-line description of each slogan is **our own paraphrase of its
traditional meaning** — deliberately not matching the wording of any
specific published translation, since that wording is copyrighted even
though the underlying teaching is centuries old and public domain. When we
actually author a `Memo Interpretation` for a slogan, that content is
original interpretation too, same process we used for `lojong-001` and
`metta-001` — this doc is just a map of what's traditionally covered, not a
source to draw phrasing from.

**Status key:** ✅ Authored · 🟡 In progress · ⬜ Not started
